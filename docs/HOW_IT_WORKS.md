# How it works

Autobot is a research system for trading strategies. Software agents propose and test
ideas continuously; people decide what, if anything, moves toward real money. Each
stage has to be earned, and nothing skips ahead.

## 1. Automated research

Research runs in labs. Each lab owns one candidate strategy and a fixed objective, and
an AI agent works on the candidate in cycles: read the results so far, change the
strategy, run it, record the outcome. A change that beats the lab's current best is
kept; anything else is discarded and logged.

Labs are grouped into populations. A population keeps a small number of fresh
trajectories exploring new directions and a few mature ones refining what already
works. A fresh trajectory that stops improving is demoted, which frees its slot for a
new one. Each population records these moves in its own log, so the search stays
visible rather than turning into a pile of experiments.

## 2. Testing

Every experiment runs through one canonical replay engine against one versioned
dataset and one versioned execution contract. The contract fixes when signals are
read, when orders execute, how fills and costs are modeled and how cash behaves. The
replay checks the contract's content hash before it runs, so a result always says
exactly which rules produced it.

Missing data is never filled in. If a required observation is absent, the session
records an explicit "no rebalance" with a reason instead of an invented price.

## 3. Evaluation

A kept experiment is a candidate, not a result. Candidates are scored on in-sample
data, then checked across separate market regimes, and must clear every regime to
qualify. Data reserved for final validation is never visible to the search. Objectives
are reviewed for what they actually reward: growth is measured above the cash rate, so
a strategy cannot win by sitting in cash.

## 4. Human review

The dashboard is where review happens. It shows each population and lab, the current
best for each, how many experiments ran, what was kept, when each lab last worked and
when it wakes next, plus full-history replays of the leading candidate against simple
buy-and-hold references. A person decides whether a candidate goes any further.

## 5. Paper trading

An approved candidate runs as a paper-trading lane on live market data with no capital
at risk. Paper results are reported separately from research and replay results and
are never mixed with them. Moving beyond paper, to small and then larger live capital,
is a separate decision with its own review.

## This demo

The repository runs the dashboard on synthetic data from `demo-data/`, generated by
`scripts/generate-demo-data.mjs`. The labs, strategies, curves and counts are invented
for illustration. The live system, its strategies and its data stay private.
